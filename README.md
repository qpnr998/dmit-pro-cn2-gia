# DMIT Pro 测评：从 1 核 TINY 到 12 核 GIANT，CN2 GIA 线路、超量限速规则和真实入手价格一次说清

搜「DMIT Pro 测评」的人，多半已经卡在同一个路口：知道这家的线路口碑好，也知道它贵，但不确定贵的部分到底买到了什么，以及哪一档才不是白花钱。

所以这篇不按跑分逐项截图，按决策顺序来讲：Pro 和 EB、T1 的真实差别在哪，洛杉矶 Pro 现在有哪些机型、各卖多少钱，超量之后会怎样，以及那几条没写在广告页上的限制。

## 先给结论，省得你往下翻

- 电信用户，且对大陆方向延迟和晚高峰稳定度有要求，Pro 是最匹配的一条线；
- 联通、移动用户，EB 系列在相近配置下给的流量更多，价格通常还更低；
- 主要面向海外用户、只是拿来做中转落地或跑国际业务，T1 就够了，没必要为 CN2 GIA 付溢价；
- 预算有限、想先试这家的质感，从 TINY 起步即可，但要注意低配机型有时只开放季付起售。

这个判断来自社区多份线路整理帖的共识：电信走 Pro，联通移动走 EB，教育网三线表现都不差。

## Pro、EB、T1：三条线的差别不是「好和坏」

DMIT 把洛杉矶机房拆成三条产品线，区别在回程路由，不在硬件。

| 系列 | 回程线路 | 到大陆的典型表现 | 适合谁 |
| --- | --- | --- | --- |
| Premium（Pro） | IPv4 三网 CN2 GIA（AS4809），IPv6 走 CMIN2 / 9929 | 电信优秀，联通、移动良好 | 电信用户、国内访客为主的站点 |
| Eyeball（EB） | IPv4 与 IPv6 三网 CMIN2 | 电信良好，联通、移动优秀 | 联通、移动用户，流量需求大 |
| Tier 1（T1） | 国际 BGP，无大陆优化 | 三线都一般，但延迟对海外访问友好 | 海外业务、中转落地 |

Pro 的去程细节是：电信走 GIA（AS4809），联通直连 AS4837，移动经香港移动（AS58453），三网回程统一 GIA。这套路由是它溢价的全部理由，和 CPU 无关。

同一个配置下，EB 往往给更多流量。以 AS3 平台的 TINY 为例，Pro 是 1TB / 1Gbps，EB 是 1.5TB / 2Gbps，两者标价同为 $10.90。如果推的是联通或移动用户，Pro 多花的这部分钱确实换不来对应的体验提升。

## 实测数据里，哪些值得看

翻了一圈测评，能稳定复现的是这几项：

**磁盘 I/O**。AS3 Pro 的 YABS 测出来平均 847 MB/s，三次取值 520 MB/s、998 MB/s、1.0 GB/s，波动主要来自测试节点负载，不是盘的问题。

**国际带宽**。iperf3 在洛杉矶本地能跑到 1.04 Gbps 上下，纽约方向约 961 Mbps，欧洲方向 500–640 Mbps。G 口是实打实的。

**IP 质量与解锁**。Pro 的 IP 段是原生 IP，风险评分普遍偏低，流媒体和 AI 服务解锁情况在多份测评里都写得比较乐观。需要注意这是概率问题，不是承诺——不同 IP 段的运气不一样。

**国内方向**。晚高峰三网 ping 基本在 150ms 以内，单线程测速抖动低、速度拉得起。这一项才是 Pro 相对 EB 和 T1 的核心差距，也是绝大多数测评真正想证明的东西。

社区里也有唱反调的帖子，有人新开的 Pro 测速只有 50Mbps，下面一排回复在追问是不是买错系列或分到了不理想的 IP 段。这种个案量级不大，但说明一件事：线路质量整体稳定，不代表每一台都完美，到手后先测一遍。

## 超量限速、退款窗口，以及几个容易被忽略的限制

**流量超了不停机**。DMIT 从 2025 年 2 月起执行限速不停机策略：流量用完后降速继续跑，而不是直接关机。Pro 系列的降速档位从 4Mbps 到 10Mbps 不等，看套餐定。对建站用户来说，突发流量不会让站点直接躺下。

**退款窗口很窄**。多篇测评和论坛帖子都提到，新购机器支持 3 天内、流量使用不超过 10G 的情况下申请全额退款，实际可能扣除支付通道产生的手续费。这个窗口短，想验证线路就趁这三天测完。

**维护通常不发邮件**。这是第三方分析里点名提到的一个真实缺点：升级宿主机时DMIT一般不会提前通知，你可能在某天突然发现服务器短暂不可用。对 SLA 有硬性要求的业务要提前想好冗余方案。

**平台成熟度差异**。AS3 平台上线后官方一直提示仍处于持续优化阶段，磁盘性能和 SLA 表现可能低于成熟平台。如果你买的是 AS3 机型，这事值得知道。

**优惠码这块别抱太大期望**。Pro 系列很少发通用折扣码，长期反复出现在各站列表里的那些码，多数是给 Lite / Standard 和部分 EB 机型的，比如年付七折的 `Lite-Annually-Recur-30OFF` 就只覆盖 Standard 线。结账页有 Validate Code 校验功能，填之前先验一遍，别默认它能用。

## 香港和东京的 Pro 值不值得

两个机房都有 Pro 线，也都比洛杉矶贵。原因很简单：亚太地区带宽成本高。香港 Pro 到大陆的延迟通常在 20–50ms 区间，这是美国机房给不了的。

划算的用法不是整台都买香港，而是香港跑主站，把 AI、大流量这类对延迟不敏感的请求分流到美西机器上。这样延迟和解锁都顾到了，钱也没多花太多。

日本 Pro 经常处于售罄状态，能不能买到要看补货节奏。如果你非东京不可，建议盯库存通知而不是隔几天手动刷一次。

## 常见问题

**Pro 和 Pro Secure 是一回事吗？**
不是。Pro Secure（sPro）在建站方向加了 Cloudflare Magic Transit 的 DDoS 防护，回程仍然是 CN2 GIA，价格更高。普通建站被攻击的概率不高，但如果你做的是容易被盯上的业务，这层防护值得单独考虑。

**年付真的更划算吗？**
年付单价更低，部分周期还会叠加流量赠送。但低配机型有时只开放月付或季付，得看下单页实际选项。如果不确定要不要长期用，先按月或季买，反而更灵活。

**建站选哪一档？**
TINY 的 1 核 2GB 跑一个轻量 WordPress 是够的，但 20GB 存储和 1TB 流量撑不了图片多的站点。中型站点建议从 MINI 起步，4 核 4GB、80GB 存储、5TB 流量，超量后还有 8Mbps 保底。

**为什么有人说 DMIT 是搬瓦工的上游？**
有第三方测评提到搬瓦工的部分 CN2 GIA 带宽从 DMIT 采购。这说明它在 GIA 资源上有实际掌控力，而不是二道转卖。这类说法来自第三方分析，不宜当作官方口径。

## 到底该怎么选

需求先定线路，再定配置，最后才看价格——顺序反了很容易多花钱。

电信用户、国内访客为主、预算有限：AS3 平台的 TINY 或 Pocket。同一套 Pro 路由，硬件弱一点，但价格低一档。

电信用户、要建站、流量吃得比较狠：AN5 平台的 STARTER 或 MINI。10Gbps 端口加 3–5TB 流量，超量后 4–8Mbps 保底，跑起来不用天天盯流量表。

联通、移动用户：先去看 EB 系列的价格和流量，再回来对比 Pro。省下来的钱够你多买一档配置。

纯海外业务或中转落地：T1，别犹豫。CN2 GIA 对你没有增益。

最后提醒一句：DMIT 的库存变化很快，官网挂出来的套餐也可能短时间售罄。确定方向后就别再拖，尤其是低配机型。
